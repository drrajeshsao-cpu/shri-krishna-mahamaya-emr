**Version:** V5.00

## मुख्य बदलाव
पुराना allopathic learning engine बहुत छोटा था: 45 generic medicines और 24 disease pathways. V5.00 में इसे large-scale research atlas में बदला गया है।

अब workflow है:
**Disease → Drug Group/Class → Mode of Action/Target → Generic Medicines → Form/Route → Adult Learning Dose Snapshot → Evidence Source → Verify → Draft Rx.**

### Coverage
- 238 disease/clinical pathways
- 177 drug groups/classes
- 371 generic/formulation records
- 27 source families
- Type 2 Diabetes में 11 major drug groups और 26 generic/formulation records

### Search
अब search कर सकते हैं:
- Disease/condition
- Drug class/group
- Mechanism / target
- Generic medicine
- System/specialty filter

### Important scientific boundary
यह coverage/research engine है, automatic prescribing engine नहीं। किसी disease के साथ class link होने का अर्थ यह नहीं कि उस class की हर medicine उस disease में approved/appropriate/first-line है। Exact indication, dose, formulation, duration, contraindications और current guideline/label clinician को verify करना होगा।

### Safety next phase
V5.00 में पहले database breadth + mechanism + dose/formulation navigation किया गया है। अगला phase source-verified renal, hepatic, pregnancy/lactation, pediatric, elderly, interactions, QT, bleeding/GI risk, monitoring और duration rules पर रहेगा।
