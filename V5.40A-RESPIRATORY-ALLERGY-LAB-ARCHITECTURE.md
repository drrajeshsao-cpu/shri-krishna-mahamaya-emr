Clinical context: asthma / COPD / allergic rhinitis / anaphylaxis / cough-mucus / acute exacerbation.  
Mechanism: beta2 / antimuscarinic / corticosteroid / leukotriene / histamine / type-2 targets.

## Scientific boundaries
Asthma and COPD treatment algorithms are not interchangeable. LABA monotherapy is not an asthma controller strategy. Inhaler device, strength, technique, adherence and phenotype matter. Anaphylaxis is an emergency: IM epinephrine is first-line; antihistamines/corticosteroids are not substitutes. All doses are learning snapshots and require current label/guideline and patient-context verification.
