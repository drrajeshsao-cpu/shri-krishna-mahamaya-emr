# Mahamaya Clinic EMR V5.00 — Modern Therapeutics Atlas

**Engine:** MTLPI v2.0  
**Build:** 2026.08.14-R20

## Why V5.00 exists
The prior modern-medicine learning engine had only 45 generic records and 24 disease pathways. V5.00 changes the architecture from a small candidate list into a scalable research atlas:

**Disease / clinical question → drug group / pharmacologic class → mechanism & target → generic medicines → dosage form / route → adult learning-dose snapshot → source family → clinician verification → optional draft prescription.**

## Coverage in this release
- 238 disease / clinical pathways.
- 177 pharmacologic drug groups / classes.
- 371 generic medicine / formulation records.
- 27 evidence / regulatory / guideline source families.
- Type 2 diabetes: 11 major pharmacologic groups and 26 indexed generic/formulation options.
- Search works by disease, alias, drug group, mechanism/target, generic medicine and selected specialty/system.

## Research-first UI
V5.00 is designed to work even when no patient is selected.

1. Search disease/question.
2. Open Drug Groups & Generics.
3. Review mechanism/target.
4. Expand each drug group to inspect generic members, form/route and adult learning-dose snapshot.
5. Open a generic monograph.
6. Use Evidence Sources for verification.
7. Draft Rx remains patient + recorded-diagnosis gated.

## Evidence-source hierarchy
The atlas points the clinician to authoritative source families rather than ranking products by marketing content. Source families include:
- WHO Essential Medicines.
- India NLEM.
- DailyMed / FDA label resources and openFDA label search.
- NICE / BNF.
- AIIMS institutional formulary / Standard Treatment Guideline resources.
- ADA diabetes standards.
- KDIGO kidney guidelines.
- ACC/AHA and ESC cardiovascular guidance.
- GINA asthma and GOLD COPD strategy documents.
- IDSA and ICMR antimicrobial guidance.
- WHO TB guidance.
- ACR rheumatology guidance.
- AASLD hepatology guidance.
- ACOG, AUA, AAD, AAO and other specialty guidance.

Manufacturer/pharma promotional pages are **not** used to rank medicines. Manufacturer-specific information should be checked against the current regulator-approved prescribing information / SmPC / package insert.

## Dose-data boundary
The `dose_example` field is an **adult learning/reference snapshot**. It is not a prescription and must not be treated as a patient-specific dose. Specialist medicines, biologics, insulin, anticoagulants, antimicrobials, TB/HIV medicines and other protocol-dependent treatments are deliberately marked as individualized/protocol-specific where a single simple dose would be unsafe or misleading.

## Important class-catalog boundary
When a disease is linked to a pharmacologic class, the expanded card displays the indexed members of that class. Class membership does **not** mean every member is approved, appropriate or guideline-preferred for every disease linked to the class. The clinician must verify disease-specific indication, local guidance and label before selection.

## Safety roadmap
V5.00 is intentionally the **coverage + pharmacology** release. The next safety-enrichment phase should systematically add source-verified:
- renal / eGFR rules,
- hepatic impairment rules,
- pregnancy / lactation,
- pediatric age/weight dosing,
- elderly/frailty precautions,
- GI/ulcer and bleeding risk,
- QT/rhythm risk,
- interaction / duplicate-class rules,
- monitoring requirements,
- duration / stop criteria,
- antimicrobial stewardship and local antibiogram gates,
- high-alert medicine handling.

Existing EMR Safety Screening remains available and should still be run before finalizing a prescription.
