# Mahamaya Clinic EMR V5.51 — Installable PWA Architecture

**Build:** 2026.08.15-R28  
**Release purpose:** convert the frozen V5.50 premium clinical workspace into a robust installable Progressive Web App without changing authentication, Firebase, role, clinical-save or therapeutic logic.

## Installation targets
- Android phone/tablet: Chromium PWA install prompt / browser install action.
- Windows laptop/desktop: Chrome/Edge standalone installed app window.
- iPhone/iPad: Safari Add to Home Screen guidance; standalone launch metadata is included.
- Existing browser usage remains supported.

## PWA hardening
- Manifest has stable id/start_url/scope and standalone display.
- Separate `any` and padded `maskable` 192/512 icons.
- Apple touch icon metadata retained; app title/mobile-web-app metadata added.
- `beforeinstallprompt` handling plus in-app Install button.
- iOS fallback guidance because iOS does not expose Chromium's programmatic install prompt.
- Versioned service-worker cache R28.
- Navigation remains network-first so current HTML/login code is preferred; cached HTML is offline fallback only.
- Firebase/CDN/auth requests are cross-origin and are deliberately not intercepted by the service worker.
- Service-worker updates never force a page reload during login or active clinical work.

## Login-preservation boundary
This release intentionally does not modify PIN validation, `unlockApp`, `lockApp`, `restoreSession`, `savePins`, Firebase configuration/sign-in/sign-out, user-role bridge, Firestore/cloud-save logic, or authorization behavior.

## Deployment requirement
Installability must be tested from the live HTTPS GitHub Pages URL. A local file (`file://`) copy is not a valid production installability test.
