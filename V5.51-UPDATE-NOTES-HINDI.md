# V5.51 अपडेट — Installable Premium Clinical App

अब Mahamaya Clinic EMR को phone, tablet, laptop और desktop पर Progressive Web App के रूप में install करने के लिए harden किया गया है।

## क्या बदला
- Version **V5.51**, Build **2026.08.15-R28**.
- Chrome/Edge/Android install prompt के लिए Install App controller.
- Windows desktop/laptop पर standalone app-window metadata.
- iPhone/iPad Safari के लिए Add to Home Screen guidance.
- 192/512 `any` icons के साथ अलग padded `maskable` icons.
- Service worker cache/version hardening और offline fallback.
- HTML navigation network-first रखा गया ताकि fresh login/UI code प्राथमिक रहे.
- Service worker active session/login के बीच automatic reload नहीं करता.

## Login/Firebase
Login, PIN, Firebase sign-in/sign-out, role bridge, credentials और cloud-save logic को जानबूझकर नहीं बदला गया है।

## GitHub publish के बाद test
1. Live HTTPS URL open करें.
2. Login test करें.
3. Install App दबाएँ (Chrome/Edge/Android) या iPhone/iPad में Safari Share → Add to Home Screen करें.
4. Installed icon से app launch करें.
5. Login → Patient → Save/Next → reopen → Firebase sync test करें.
