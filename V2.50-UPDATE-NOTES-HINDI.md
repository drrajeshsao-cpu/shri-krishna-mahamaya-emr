# Mahamaya Clinic EMR V2.50 — Clinical Command Center

Date: 13-08-2026

## What changed
- App-like responsive home screen and dashboard.
- Fast patient search at the top of Home.
- 10-step clinical workflow: Patient → Complaint → Clinical → General → Systemic → Investigations → Ayurveda → Prescription → Safety → PDF.
- Organized module drawer instead of a crowded 20+ button header.
- Desktop primary navigation and mobile bottom navigation.
- Today OPD queue, recent patients, KPIs and current-patient context.
- Faster one-tap access to CBC, labs, imaging, pharmacy, billing and appointments.
- Desktop shortcuts: Alt+N, Alt+S, Alt+R, Alt+P.
- Corrected PWA files: service-worker.js and install-pwa.js are now real JavaScript.
- Corrected 192/512 app icons and added Apple touch icon.
- Cache version bumped to V2.50 to reduce old-build/cached deployment confusion.

## Preserved
All existing V2.49C clinical sections, Ayurveda structured data, patient records, prescription logic, Firebase authentication config/storage key compatibility, backup/settings and existing IDs/event handlers are retained.
