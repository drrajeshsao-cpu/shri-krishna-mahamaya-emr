# Mahamaya Clinic EMR V5.55.1 — Performance Hotfix
Build: 2026.08.15-R32H1

## Problem corrected
V5.55 `clinical-exam-command-center-v3.js` used a subtree MutationObserver. Its callback updated the Active-module text node, which could itself generate another observed mutation. On some Chromium/Edge sessions this created a self-triggering main-thread loop, producing “This page isn't responding” while the login screen remained at “Firebase se connect ho raha hai…”.

## Hotfix
- Replaced v3 with `clinical-exam-command-center-v3.1.js`.
- Removed MutationObserver completely.
- Added requestAnimationFrame-coalesced refresh only for real examination input/change events.
- Added only bounded one-shot initialization retries.
- New asset filename bypasses an already-cached V5.55 broken script on the very first post-deploy reload.
- Service-worker cache name bumped to V5.55.1 R32H1.
- Login, PIN, Firebase authentication and clinical schemas are not changed.

## Deployment note
After GitHub Pages updates, perform one hard refresh (Ctrl+Shift+R). If an installed PWA is open, close all Mahamaya EMR windows and reopen once so the new service worker can take control.
