# V5.40X — Pharmacogenomics • Precision Medicine • Genotype–Drug Safety Intelligence Lab

Build: **V5.40X • MTLPI v2.4X • PGx v1.0 • R25X**

## Scope
Cross-cutting clinician-reviewed pharmacogenomics workspace for translating a verified laboratory result into a drug-specific safety/response review. It covers assay/report verification, diplotype→phenotype translation, phenoconversion/drug–gene–drug context, HLA severe-reaction signals, CYP metabolizer phenotypes, transporters, DPYD, TPMT/NUDT15, UGT1A1, G6PD, MT-RNR1 and malignant-hyperthermia susceptibility examples.

## Dataset
- **44 PGx classes / gene–drug workflows**
- **88 detailed clinical + implementation profiles**
- Cumulative: **30 specialized labs • 965 classes • 2185 profiles**

## Safety architecture
1. Preserve the original laboratory result verbatim.
2. Verify patient/specimen identity, assay method, allele coverage and report date.
3. Translate diplotype/variant to phenotype using the current gene-specific standard.
4. Check phenoconversion and drug–gene–drug interactions.
5. Match the exact medicine + indication to current CPIC/FDA labeling/specialty guidance.
6. Keep non-genetic modifiers visible: age, organ function, interactions, pregnancy/lactation, disease severity, TDM and clinical response.
7. Require clinician confirmation before therapy changes.

**The app does not order PGx testing, infer unreported alleles, generate a genotype-based dose, automatically substitute/stop therapy, or declare a medicine safe/unsafe.**

## Evidence anchors
- CPIC/ClinPGx — current clinical pharmacogenetics guidelines and gene–drug pair levels.
- FDA — Table of Pharmacogenetic Associations.
- FDA — Pharmacogenomic Biomarkers in Drug Labeling.
- ClinPGx (PharmGKB + CPIC + PharmCAT) — clinical PGx implementation/reference ecosystem.

## Important interpretation boundary
CPIC guidance is primarily about **how to use an available genotype result**, not a universal instruction that every patient must be tested before every listed drug. FDA likewise notes that inclusion of an association does not automatically mean testing is required unless applicable labeling/companion-diagnostic requirements say so.
