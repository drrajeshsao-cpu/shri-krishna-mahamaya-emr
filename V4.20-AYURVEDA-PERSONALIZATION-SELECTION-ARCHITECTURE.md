# Mahamaya Clinic EMR V4.20 — Ayurveda Personalization & Selection Navigator

Build: 2026.08.14-R18  
MATLI: v1.4

## Why this release
V4.10 displayed Prakriti, Vikriti, Agni, Ama, Koshtha and Rogi/Roga Bala as read-only context cards inside MATLI. Users could reasonably interpret them as buttons, but they were display-only. V4.20 converts them into explicit assessment links and closes the workflow loop between Ayurveda Assessment and Ayurveda medicine research.

## Interactive personalization bridge
The six cards now open the relevant Ayurveda Assessment field:
- Prakriti → Quick Ayurveda / Prakriti
- Vikriti → Quick Ayurveda / Vikriti
- Agni → Samprapti / Agni–Ama–Koshtha assessment
- Ama → Samprapti / Agni–Ama–Koshtha assessment
- Koshtha → Samprapti / Agni–Ama–Koshtha assessment
- Rogi/Roga Bala → Samprapti / Diagnosis–Bala–Prognosis engine

Returning to Prescription refreshes MATLI patient context automatically.

## Individualized medicine-selection context
A collapsible context panel summarizes documented Roga/diagnosis, Prakriti, Vikriti, Agni, Ama, Koshtha, Rogi/Roga Bala, Satmya, Vaya/age and concurrent medicines. Missing information remains explicitly marked Not assessed/Not documented.

## Classical + modern prescription verification checklist
Every Ayurveda monograph/discovery record now carries a verification framework covering:
1. Roga / diagnosis & avastha
2. Prakriti
3. Vikriti / dominant Dosha
4. Agni + Ama/Nirama
5. Koshtha
6. Rogi Bala + Roga Bala
7. Satmya + Vaya
8. Desha + Kala/season
9. Concurrent medicines/comorbidity
10. Exact identity, quality and source
11. Matra + Anupana + Aushadha Sevana Kala
12. Duration + monitoring + stop criteria

The framework organizes clinician review; it does not infer formulation-specific suitability when evidence is absent.

## Formulation comparison
V4.20 adds Compare to formulary result cards. Up to four formulations can be compared side-by-side for:
- curated vs AFI-discovery layer
- evidence tier
- formulation class
- risk tier
- current clinical-situation safety status
- dose verification status
- encoded clinical/index context

Comparison is research-navigation support, not an automatic Drug-of-Choice ranking.

## Source hierarchy
S1: PCIM&H API/AFI official pharmacopoeia/formulary sources.  
S2: Ministry/CCRAS government treatment protocols and essential-medicine resources.  
S3: CCRAS, AIIA, NIA and AIIMS integrative/clinical research resources.  
S4: Ayush Suraksha / pharmacovigilance and WHO safety resources.

## Safety boundary
Missing dose, pregnancy, pediatric, renal, hepatic, interaction or duration data never means safe. Exact formulation identity, processing, composition, dose, frequency, Anupana, Kala, duration, quality and patient-specific suitability must be verified from the applicable authoritative source/licensed label and clinical context.
