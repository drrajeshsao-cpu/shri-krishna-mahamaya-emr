# Mahamaya Clinic EMR V5.01 — Modern Atlas Interaction Hotfix

Build: 2026.08.14-R21  
MTLPI: v2.0 (dataset unchanged)

## Root causes repaired
1. The six top workflow controls in V5.00 were visual `<div>` steps, not interactive buttons.
2. Disease/class selection could set an invalid internal tab state (`groups`) although the rendered pane is named `therapy`, hiding results after Search Atlas / quick search / Use Patient Context.

## V5.01 interaction contract
- Disease / question: opens Research Context and focuses search.
- Drug groups: opens drug-group/generic pane.
- Mechanism / target: opens the therapy pane and expands a mechanism-bearing class card when present.
- Generic options: navigates to the generic rows.
- Dose / formulation: opens the selected generic monograph; if none is selected it explicitly asks the user to choose a generic.
- Verify & draft: opens Evidence Sources; Draft Rx remains patient/diagnosis gated.
- Search Atlas: works by click and Enter.
- Use Patient Context: maps to a valid therapy pane.
- Reset: clears search, selection, filter, navigation and feedback state.
- Research tabs, quick examples, search-result rows, Monograph, Draft Rx and Add Dx remain wired.

## Safety boundary
This is a navigation/interaction hotfix only. MTLPI v2.0 data counts and coverage are unchanged; V5.10+ remains the planned systematic safety/interaction/special-population phase.
