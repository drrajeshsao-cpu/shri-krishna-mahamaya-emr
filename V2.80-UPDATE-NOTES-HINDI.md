# Mahamaya Clinic EMR V2.80 — Responsive Clinical Workspace

Build: 2026.08.13-R3

## लक्ष्य
Mobile, tablet, laptop और desktop पर एक ही clinical sequence को तेज, स्पष्ट और कम-scroll workflow में चलाना। V2.80 का design किसी एक commercial EHR की copy नहीं है; 20 leading medical/practice-management systems से recurring workflow principles लेकर Mahamaya Clinic की Ayurveda + modern medicine जरूरतों के अनुसार hybrid architecture बनाया गया है।

## V2.80 में मुख्य बदलाव
- Device-adaptive responsive layout: phone, tablet, laptop और wide desktop के लिए अलग density/breakpoint behavior.
- Global Active Patient Dock: patient name, UHID, visit, online/offline और last save state हमेशा उपलब्ध।
- Fast Clinical Flow drawer: Patient → Complaint → History/Vitals → General → Systemic → Assessment/Dx → Investigations → Ayurveda → Rx → Safety → PDF.
- Mobile bottom navigation में dedicated **Flow** button।
- Laptop/desktop के लिए **Compact density** mode, जिससे कम scrolling और अधिक data एक screen पर दिखता है।
- Tablet पर cramped 3-column forms को adaptive 2-column layout में बदलना।
- Phone पर 16px inputs, 44–46px touch targets, bottom-sheet Fast Flow और thumb-friendly actions।
- Data Safety & Sync card: network state, Firebase session, last save time और manual sync button।
- Save transparency: local save और cloud save state अलग दिखती है; cloud failure को “secure/synced” के रूप में गलत नहीं दिखाया जाता।
- Existing SLAIE Core v1.0, Omega Exact-Row Template v1.0, editable terminology, modular Ayurveda workspace और patient schema preserve किए गए हैं।
- PWA manifest में Fast Flow shortcut जोड़ा गया और cache version V2.80-R3 किया गया।

## Applied design principles
- One patient context across modules
- One visible next step / encounter path
- Search-first records and terminology
- Customizable structured + free-text charting
- Mobile parity, not a reduced “viewer-only” mobile screen
- Integrated investigations/labs within patient chart
- Safety before final prescription
- Clear local/cloud save state
- Fewer top-level buttons; secondary tools remain in drawers
- Responsive density rather than stretching desktop UI onto phones

## Important production note
V2.80 improves workflow and exposes sync/save state, but it does not by itself certify the app for production healthcare data. Before real-patient production use at scale, Firestore security rules, backend role enforcement, backup/restore, retention/privacy policy and security review must be tested and documented.
