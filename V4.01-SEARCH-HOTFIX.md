# Mahamaya Clinic EMR V4.01 — Formulary Search Hotfix

Build: 2026.08.14-R16
MATLI: v1.2

## Fixed
- `Search Formulary` now performs a patient-independent Ayurveda library/research search.
- `Use Patient Encounter` is now clearly separated from formulary research search.
- Pressing Enter in the search field runs the formulary search.
- Formulation class matching is grouped across curated MATLI and AFI naming differences.
  - Example: `Rasaushadhi / Herbo-mineral` now also matches AFI `Rasayoga / Rasaushadhi` and `Kupipakva Rasayana`.
- `High-caution only` now works for both curated and AFI-index records.
- Research results render as a persistent list in `2 • Formulation Candidates`, not only as a temporary dropdown.
- Header/manifest/service-worker version and cache updated to V4.01 / R16.

## Intended workflow
Research: Kasa → Rasaushadhi / Herbo-mineral → Curated + AFI index → High-caution only → Search Formulary.
Clinical: select patient / document complaint or diagnosis → Use Patient Encounter → review individualized context and safety gates.

Research results are discovery/learning references, not automatic prescriptions.
