# Mahamaya Clinic EMR V5.52 — Ayurveda Devanagari / Bilingual Medicine Names

**Build:** 2026.08.15-R29  
**Scope:** Ayurveda Scientist Workspace / MATLI display and search layer only  
**Clinical/authentication boundary:** No change to login, PIN, Firebase authentication, roles, cloud-save, medicine IDs, source IDs, dose logic, safety gates or clinical decision rules.

## Purpose
Ayurveda formulation names are Sanskrit-origin names and are often more natural to read in Devanagari. V5.52 adds a reversible display/search layer so clinicians can work with medicine names in Devanagari, English/Roman source spelling, or both.

## Display modes
- **देवनागरी + English** — default. Source-verified/curated Devanagari appears as the primary name with Roman spelling beneath it. For automatically generated transliterations, the Roman/source spelling remains primary and the Devanagari form is labelled as `लिप्यंतरण`.
- **केवल देवनागरी** — Devanagari display mode.
- **English** — original Roman/source spelling only.

The preference is saved locally with `mahamaya_ayu_name_lang`; it is not part of Firebase authentication or patient data.

## Search behavior
Search accepts both scripts. Examples:
- `Kasa` or `कास`
- `Shwasa` or `श्वास`
- `Sitopaladi` or `सितोपलादि`
- `Sutashekhara` / `Sutshekhar` or `सूतशेखर`
- `Bhasma` or `भस्म`
- `Lauha` or `लौह`

The Devanagari index covers:
- 188 curated MATLI medicine/formulation records
- 640 AFI discovery records
- 39 Ayurveda clinical context records
- **867 mapped records total**

## Source fidelity
Canonical record IDs and original Roman/source names are preserved. Devanagari aliases are held in a separate file `ayurveda-devanagari-map-v1.json` so the clinical/source datasets remain unchanged.

Common formulations have curated display overrides, including examples such as:
- कनकासव — Kanakasava
- सितोपलादि चूर्ण — Sitopaladi Churna/Curna
- तालीसादि चूर्ण — Talisadi Churna/Curna
- मधूकासव — Madhukasava
- वासकासव — Vasakasava
- श्वास कास चिन्तामणि रस — Svasa Kasa Cintamani Rasa
- सूतशेखर रस — Sutashekhara/Sutshekhar Rasa
- त्रिफला चूर्ण — Triphala Churna
- योगराज गुग्गुलु — Yogaraja Guggulu

For rare AFI index spellings, automatic transliteration can be imperfect because source Roman text may omit Sanskrit diacritics. Therefore V5.52 never silently replaces the canonical source spelling; exact Sanskrit orthography should be verified from the authoritative AFI/API/classical source when clinically or academically important.

## Prescription draft behavior
When a curated Devanagari override exists and `दोनों` mode is active, loading a formulation name to the draft uses `देवनागरी (Roman)` while leaving dose/anupana/kala/duration blank as before. No autonomous prescribing is introduced.

## Responsive design
The language switch is responsive and works inside the existing V5.51 installable PWA on mobile, tablet, laptop and desktop. System Devanagari fonts are preferred (`Nirmala UI`, `Mangal`, `Kohinoor Devanagari`, `Noto Sans Devanagari`) without adding a web-font dependency.
