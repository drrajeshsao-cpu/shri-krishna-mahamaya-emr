# V5.53 अपडेट — Clinical Examination Research Fast Flow

## मुख्य बदलाव

Clinical Examination को अब तीन workflow modes में व्यवस्थित किया गया है:

- **⚡ FAST** — 10 core findings का rapid screen: Not assessed / Absent / Present.
- **🩺 STANDARD** — rapid screen + पुराने detailed finding-specific grade, site, remarks और Details intact.
- **🧪 RESEARCH** — structured assessor/visit metadata, explicit missingness, documentation completeness और export-ready JSON.

## Fast Flow additions

- Vitals का read-only snapshot — BP, Pulse, SpO₂, Temperature, RR, Pain, BMI.
- General appearance structured block — condition, consciousness, orientation, posture, cooperation, speech/interaction.
- Abnormal-only filter.
- “Screened absent” bulk action केवल clinician confirmation के बाद.
- Empty findings को normal मानने के बजाय “Remaining not assessed” action.
- Present finding के लिए direct Details open.
- Next Focused → Oedema / Gait / Pain / Interpretation.
- Top-level Save & Next → existing Systemic workflow.

## Research / Scientist additions

- MCE-RP1 v1.0 protocol identity.
- Routine OPD / Screening / Baseline / Follow-up / Post-intervention / Event visit tagging.
- Assessor, setting, position, verification, dataset status, limitations और study tag.
- Documentation % और Clinically Assessed % अलग-अलग.
- Structured research summary.
- Copy JSON / Download JSON.
- Patient identity export OFF by default; pseudonymized subject code used by default.

## महत्वपूर्ण safety

- Not assessed ≠ Absent / Normal.
- Documentation percentage कोई validated clinical quality या severity score नहीं है.
- Existing Oedema, Gait, Pain, Explainable CDS और Systemic Examination preserved हैं.
- Login/PIN/Firebase/role/cloud logic को modify नहीं किया गया.
