# Mahamaya Clinic EMR V2.70 — Mobile Clinical Workspace + SLAIE

Build: 2026.08.13-R2

## Main changes
- Added **SAO Lab AutoRead & Interpretation Engine (SLAIE)** under Investigations.
- Preserved finalized naming: **SLAIE Core v1.0 — Omega Exact-Row Template v1.0**.
- PDF AutoRead (lazy-loaded PDF.js), image/camera OCR (lazy-loaded Tesseract.js), editable extracted text, exact-row mapping, clinician verification, lab-specific reference ranges/units, interpretation, patient Investigations insertion, and per-patient archive.
- Original report file is stored locally in IndexedDB when the browser supports it.
- Complaint search remains fully editable and now loads **1185 searchable terms** across symptoms, diseases/conditions, Ayurveda terms and saved custom terms.
- Complaint Search Scope can switch between All / Symptoms / Diseases / Ayurveda / My Terms.
- Ayurveda page is divided into Quick Ayurveda, Ashtavidha-Dashavidha, Samprapti-Nidana, Chikitsa, Follow-up, Extended Clinical Tools and System/Admin views. Only one detailed group is displayed at a time to remove very long scrolling.
- Mobile workflow has larger touch targets, sticky action areas, horizontally scrollable SLAIE verification table, direct camera upload and PWA install CTA.
- Existing V2.60 workflow, Firebase authentication/cloud-save logic, patient records and prescription structure are preserved.

## Important safety
SLAIE is clinician decision support. The original report is the source of truth; verify identity, date/specimen, result, unit, flag and reporting laboratory reference interval before clinical use.
