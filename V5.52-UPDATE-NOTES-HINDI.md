# V5.52 अपडेट — Ayurveda Devanagari / Bilingual Medicine Names

अब Ayurveda Scientist Workspace में **औषधि नाम** switch उपलब्ध है:

- **देवनागरी + English** — default और recommended
- **केवल देवनागरी**
- **English**

Search भी दोनों scripts में काम करेगा, जैसे `Kasa / कास`, `Shwasa / श्वास`, `Sitopaladi / सितोपलादि`, `Bhasma / भस्म`, `Lauha / लौह`।

Common Ayurvedic formulations में Devanagari नाम primary दिखेंगे और English/Roman spelling नीचे छोटी line में रहेगी। Rare AFI discovery spellings में, जहाँ exact Sanskrit orthography source-verified नहीं है, Roman/source spelling primary रखी गई है और Devanagari को `लिप्यंतरण` के रूप में दिखाया जाता है।

**महत्वपूर्ण:** यह display/search upgrade है। Login, PIN, Firebase authentication, roles, cloud sync, patient saving, medicine IDs, dose logic और existing safety rules में कोई बदलाव नहीं किया गया।
