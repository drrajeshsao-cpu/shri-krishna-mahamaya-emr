# Mahamaya Clinic EMR V4.30 — Ayurveda Scientist Workspace

Build: 2026.08.14-R19  
MATLI: v1.5

## Goal
Convert the Ayurveda therapeutics page from a long feature stack into a compact researcher/practitioner workspace with a clear scientific sequence and less visual duplication.

## Workspace model
1. Clinical question
2. Patient context (optional for research, required for individualized clinical use)
3. Search evidence/formulary
4. Compare candidates
5. Verify monograph + safety + source
6. Clinician-controlled draft prescription

## UI changes
- Default tab is **Search & Compare** rather than patient context.
- Research mode and Patient mode are visibly distinguished.
- Safety boundary is retained but collapsed by default.
- Primary search controls are visible; source/risk/high-caution controls move under Advanced Filters.
- Prakriti, Vikriti, Agni, Ama/Nirama, Koshtha and Rogi/Roga Bala remain clickable inside a dedicated Patient Context tab.
- Stale form values cannot create a complaint/diagnosis context when no patient is selected.
- Complaint-derived possible Ayurveda contexts are collapsed instead of occupying the page.
- Empty research screen provides quick examples and a five-step scientific flow.
- Reset control clears research filters, comparison set and search state.

## Safety boundary
This remains a clinician-learning/research navigation layer. No missing safety field is interpreted as safe. AFI discovery entries are not prescribing monographs. Dose, Anupana, Kala, duration, interactions, organ-function and special-population statements require source verification.
